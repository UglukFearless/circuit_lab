# Overview

## Цель
Освоить проектирование и моделирование электрических цепей через чат с ИИ-агентом
(«САПР как код»), с визуальным представлением результатов.

Требования к данным:
- всё в **текстовых, детерминированных** форматах — ИИ работает с текстом, ошибки должны быть выражены точно;
- форматы и инструменты — **общепринятые**, чтобы результаты не были уникальным артефактом.

## Режим работы — одно окно
Работа идёт в одном окне: диалог с LLM, изредка правка руками.
- Агент сам запускает инструменты через консоль (`kicad-cli`, ngspice, Python) — GUI не нужен.
- Результаты (SVG схем, графики, отчёты) открываются прямо в редакторе.
- GUI-приложения (редактор KiCad) — только как запасной вариант для ручной правки.
- Внешние системы (доски, вики, дашборды) — через MCP.

## Подход
- Схема описывается **текстом** (источник истины), визуализация — производная.
- Варианты подключения сравниваются программно.
- Логические дефекты (проходные выключатели, зависимости) — граф соединений + перебор состояний.
- Аналоговые эффекты (тление LED, последовательное включение нагрузок, наводки) — SPICE.

## Стек
| Роль | Инструмент |
|---|---|
| Источник истины схемы | `.kicad_sch` (KiCad) |
| Картинка схемы, экспорт нетлиста | `kicad-cli` |
| Симуляция | ngspice (поставляется с KiCad), формат — SPICE-нетлист |
| Анализ, графики | Python (uv), PySpice, matplotlib |
| Топология проводки | Graphviz / Mermaid |
