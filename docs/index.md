# circuit_lab

circuit_lab — проектирование и моделирование электрических цепей в диалоге с ИИ-агентом. Исходники — схемы KiCad, SPICE-модели и Python-скрипты; агент правит их и запускает инструменты.

## Функции

Для каждой модели цепи проект выдаёт изображение схемы (SVG), SPICE-нетлист и XML-нетлист KiCad. Сценарий цепи выдаёт таблицу измерений по всем наборам значений входов модели и осциллограммы каждого прогона.

## Термины

| Термин | Значение |
|---|---|
| модель цепи | схема KiCad с назначенными SPICE-моделями; единственный источник истины о цепи |
| вариант | одна из моделей цепи одного объекта, различающихся топологией |
| вход модели | свободный параметр модели цепи; значение задаёт сценарий |
| выходные файлы | файлы, получаемые из моделей цепей сборкой или сценарием; хранятся в `build/` |
| сборка | получение изображений и нетлистов из моделей цепей |
| сценарий | программа, которая задаёт значения входам модели, запускает симуляцию для каждого набора значений и вычисляет измерения |
| библиотека моделей | SPICE-модели компонентов, общие для всех цепей |
