# Люстра: пять ламп, двухклавишный выключатель

## Устройство

Двухклавишный выключатель с клавишами B1 и B2 коммутирует фазу. Люстра на пять LED-ламп (заявлены как аналог 60 Вт); в корпусе люстры только провода. С потолка в люстру приходят нейтраль и две фазы с выключателя; PE не подключён.

У каждой лампы два провода: коричневый и синий. В люстре они собраны в три узла, каждый соединён с одним проводом с потолка:

| Узел | Провода ламп |
|---|---|
| `X_BLUE` | синие провода всех пяти ламп |
| `X_BR2` | коричневые провода ламп группы G2 (LA1, LA2) |
| `X_BR3` | коричневые провода ламп группы G3 (LA3–LA5) |

## Варианты

Варианты различаются подключением проводов с потолка к узлам люстры:

| Узел | «Как есть» (`chandelier_as_is`) | «Исправленный» (`chandelier_fixed`) |
|---|---|---|
| `X_BLUE` | фаза через B1 | нейтраль |
| `X_BR2` | нейтраль | фаза через B1 |
| `X_BR3` | фаза через B2 | фаза через B2 |

## Режимы

Режим задают положения клавиш B1, B2 (входы `b1`, `b2`). Для каждого режима рассчитывается переходный процесс 200 мс; измеряется действующее напряжение на каждой лампе на интервале 100–200 мс. Сценарий — `sim/run_cases.py`, отчёт — `build/sim/results.md`.

Действующее напряжение на группах ламп, В (модель лампы `lamp_r` — резистор, эквивалентный 8 Вт при 230 В):

| B1 | B2 | «Как есть»: G2 / G3 | «Исправленный»: G2 / G3 |
|---|---|---|---|
| разомкнута | разомкнута | 0 / 0 | 0 / 0 |
| замкнута | разомкнута | 230 / 0 | 230 / 0 |
| замкнута | замкнута | 230 / 0 | 230 / 230 |
| разомкнута | замкнута | 138 / 92 | 0 / 230 |

В варианте «как есть» при замкнутых B1 и B2 на обоих выводах ламп G3 одна фаза, и G3 не горит. При разомкнутой B1 и замкнутой B2 узел `X_BLUE` не подключён к сети: группы G3 и G2 включены последовательно между фазой и нейтралью, и напряжение делится между ними обратно числу ламп в группе.
