# 0002 Преобразование проекта

## Цель

Привести проект к виду репозитория `circuit_lab`, из которого рабочее окружение воспроизводится скриптом установки: документация с индексом, цепи в отдельной папке со сборкой в соответствующие выходные папки, зависимости по манифесту со скриптом установки, обобщённые сценарии, живая симуляция в браузере.

## Решения

Название проекта — `circuit_lab`; удалённый репозиторий — `https://github.com/UglukFearless/circuit_lab.git`. Имя локальной папки не меняется. В `pyproject.toml` и окружении `.venv` до выполнения этапа 2 действует прежнее имя `lighting-model`.

Документация на русском; код, входы и выходы программ на английском ([conventions.md](../../conventions.md)).

Цепи хранятся в `circuits/<цепь>/`: проекты KiCad вариантов и сценарии цепи. Производные — в `build/<цепь>/` с той же структурой.

Зависимость проекта — компонент, необходимый для работы, но не являющийся частью проекта. В репозитории хранится ссылка на неё (версия, источник, способ проверки) и способ установки; сами файлы зависимостей — нет. Зависимости из winget описываются файлом `.config/configuration.winget` (команда `winget configure`), остальные — манифестом `tools/deps.toml`. Сторонний проект без версионированных сборок описывается репозиторием, коммитом и командой сборки.

Живая симуляция — CircuitJS (`pfalstad/circuitjs1`, GPL-2.0): собирается из закреплённого коммита (Gradle 8.7 wrapper, GWT 2.8.2, Temurin JDK 8 — как в CI автора). Схема для CircuitJS — выходной файл сборки из модели KiCad: геометрия из `.kicad_sch` (`kiutils`), типы элементов по символам. Сценарии выполняются в ngspice.

Целевая структура:

```
README.md                    описание, установка, запуск
AGENTS.md                    правила для агентов, указатель на docs/
docs/                        документация (index.md)
circuits/<цепь>/             проекты KiCad вариантов, scenarios.toml
lib/spice/models.lib         библиотека моделей
tools/                       setup.py, build.py, simulate.py, serve.py, deps.toml, circuit_tools/ (общий код)
.config/configuration.winget зависимости из winget
web/                         страница живой симуляции
build/<цепь>/                выходные файлы: schematics/, netlists/, sim/, circuitjs/
.deps/                       скачанные и собранные зависимости
```

## Этапы

| # | Этап | Готово, когда | Статус |
|---|---|---|---|
| 0 | git: репозиторий, `.gitignore`, `.gitattributes`, первый коммит, `origin` | первый коммит — состояние до преобразования | выполнен |
| 1 | документация: разделы с индексом, правила ведения, README, сокращённый AGENTS.md | сведения, нужные для работы, находятся через `docs/index.md`; AGENTS.md — меньше 60 строк | в работе |
| 2 | структура: `circuits/`, `lib/`, `tools/`, общий код, выход в `build/<цепь>/`, имя `circuit_lab` в `pyproject.toml` | сборка и сценарий дают те же SVG и те же напряжения, что до преобразования | не начат |
| 3 | зависимости: `configuration.winget`, `deps.toml`, `setup.py` с режимом проверки; пути к инструментам из манифеста | `setup.py --check` на рабочей машине без замечаний; повторная установка ngspice в `.deps/` со сверкой SHA256 | не начат |
| 4 | обобщённые сценарии: `scenarios.toml` цепи, общий исполнитель, `results.json` | таблица для люстры получается без кода, специфичного для люстры | не начат |
| 5 | живая симуляция: сборка CircuitJS, конвертер KiCad → CircuitJS, страница `web/`, `serve.py` | схема люстры в браузере повторяет схему KiCad, Run/Stop и ключи работают, в положении «B1 разомкнут, B2 замкнут» напряжения совпадают с ngspice | не начат |
