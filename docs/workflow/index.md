# Порядок работы

## Задачи

Работа ведётся задачами. Каждая задача — документ `tasks/NNNN-slug.md`: четырёхзначный порядковый номер и краткое имя через дефис.

Документ задачи состоит из разделов «Цель», «Решения», «Этапы», «Итог». Этапы — таблица со столбцами «#», «Этап», «Готово, когда», «Статус». Статус этапа — «не начат», «в работе» или «выполнен».

Задача открыта, пока не выполнены все этапы и не записан итог; после этого она закрыта. Сведения, ставшие действующими после выполнения этапа, переносятся в разделы документации по их предмету.
