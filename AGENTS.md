# AGENTS.md

Проект circuit_lab: моделирование электрических цепей в диалоге с ИИ-агентом. Документация — [docs/index.md](docs/index.md); перед работой с разделом читается его индекс.

## Правила

- Документация ведётся по [docs/conventions.md](docs/conventions.md).
- Задачи ведутся по [docs/workflow/index.md](docs/workflow/index.md).
- Агент предлагает план; согласие с деталями плана не означает команды на выполнение. Выполнение начинается только по явной команде пользователя. После каждого этапа агент отчитывается и ждёт команды на следующий.
- Новый файл, папку, зависимость или установку агент объявляет с назначением и выполняет после согласия пользователя. Правки внутри согласованных файлов согласования не требуют.
- ПО скачивается только с официальных сайтов проектов. Файловое хранилище стороннего сервиса допустимо только когда на него ссылается официальный сайт проекта.

## Git

- Указывать соавторство в коммитах и PR запрещено.
- Push выполняется только по команде пользователя.
